SMS Configuration (Cellcast)

Notifications go out as free in-app push first; SMS (powered by Cellcast, an Australian gateway billed in AUD) is the fallback for workers without the app. To enable SMS, set these environment variables on the server:

CELLCAST_API_KEY=your_cellcast_appkey

CELLCAST_SENDER_ID=RAW Labour (optional — costs more per SMS; leave blank for the cheapest shared number)
